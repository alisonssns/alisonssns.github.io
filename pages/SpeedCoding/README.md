## Execução do Projeto

Este projeto exige a execução do frontend (React) e do backend (Node.js) em terminais separados.

---

### 1. Iniciar Frontend (React)

Na raiz do projeto, use:

```bash 
npm run dev
```

Este comando irá iniciar o servidor de desenvolvimento do **React**.

---

### 2. Iniciar Backend (Node.js)

Em outro terminal, siga:

```bash
cd backend
```

```bash
node node.js
```

Este comando irá iniciar o **servidor backend**.

---

### 3. Começar

Por fim entre ná rota localhost que o npm run dev te disponibilizou.
